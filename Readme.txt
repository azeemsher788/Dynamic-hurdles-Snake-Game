Created through only Turtle library and using OOP concepts in python.

1.Include time, health and printing player name.
2.if snake head collide with dynamic hurdles or snake_body then game over.
3.If health reach to zero then game over.
4.if snake_body except head collide with dynamic hurdles, reduce the health
  and change the hurdle color to firstly Red, after second time collision Dark Red.
5.Every time after eating five blue grains a large grain appear,
  by eating it score increase to 10 times and health increase to 3 times.
  
It contains snake_game.sh file, if you are Ubuntu user and having python 
installed on your system then just right click to run as a program
